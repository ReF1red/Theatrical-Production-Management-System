# Theatrical-Production-Management-System
# Система управления театральными постановками

# Назначение
# Приложение для автоматизации работы театра:учёт постановок репертуара, контроль готовности спектакля, расчёт стоимости билетов и подбор актёров. Приложение заменяет ручное ведение данных и снижает число ошибокпри организации показов

# Целевая аудитория
# администраторы и руководители театров.

# Предметная область
# Предметная область — организация театральной деятельности.

# Основные сущности
# Постановка — название, автор, жанр, дата премьеры, статус готовности;
# Актёр — имя, пол, возраст;
# Роль — название, требуемый пол актера, требуемый возраст актера;
# Показ (сеанс) — дата и время показа постановки;
# Билет — зона зала, цена, категория зрителя (полный / льготный);
# Зрительный зал — зоны и вместимость.

# Основные функции
# определение статуса постановки по степени готовности (репетиции, костюмы, декорации);
# расчёт стоимости билета с учётом зоны зала и льготной категории зрителя;
# проверка соответствия актёра требованиям роли по половому и возрастному признаку;

# План развития
# На следующих этапах планируется:
# - разработка веб-приложения;
# - подключение базы данных;
# - реализация пользователей;
# - разработка API;
# - контейнеризация приложения;
# - настройка CI/CD.
