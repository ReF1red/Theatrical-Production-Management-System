# Система управления театральными постановками

Консольное приложение для автоматизации работы театра: ведение репертуара,
контроль готовности спектаклей, работа с показами и бронированиями билетов,
расчёт стоимости билетов и подбор актёров на роли.

## Развитие проекта относительно ПР1

В ПР1 логика работала с отдельными переменными. В ПР2 исходные функции
`get_production_status()`, `calculate_ticket_price()` и `can_cast_actor()`
сохранены и включены в модульную структуру проекта. Данные переведены в
коллекции и JSON-файлы, добавлены поиск, сортировка, генератор, бронирование,
статистика, обработка исключений и автоматизированные тесты.

## Возможности

- просмотр, поиск и сортировка постановок;
- фильтрация постановок по жанру с использованием генератора;
- добавление постановок и изменение их готовности;
- ведение списка показов;
- проверка доступности места;
- создание и отмена бронирований;
- расчёт стоимости билетов по зоне и категории зрителя;
- подбор актёров на роли;
- расчёт статистики по бронированиям;
- сохранение и загрузка данных из JSON-файлов;
- защита от некорректного ввода и ошибок файлов.

## Структура проекта

- `main.py` — точка запуска и меню приложения;
- `productions.py` — постановки, поиск, сортировка, статус готовности;
- `shows.py` — показы спектаклей;
- `bookings.py` — бронирования и статистика;
- `tickets.py` — расчёт стоимости билетов;
- `casting.py` — подбор актёров на роли;
- `storage.py` — чтение и запись JSON;
- `utils.py` — безопасный пользовательский ввод;
- `data/` — данные приложения в JSON;
- `tests/` — автоматизированные тесты pytest.

## Требования

- Python 3.10+;
- pytest;
- flake8.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

```bash
flake8
```

## Использованные возможности Python в ПР2

В проекте применяются списки и словари, циклы `for` и `while`, функции,
пользовательские модули, обработка исключений, контекстный менеджер `with`,
JSON-файлы, аннотации типов, генератор через `yield` и `lambda` для сортировки.
