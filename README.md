# Театральные постановки

Учебный проект: постановки, показы, билеты и подбор актёров.
Есть консольное меню и сайт на Django. Данные хранятся в JSON.

Нужен Python 3.10 или новее.

## Запуск

Консоль:

```bash
python main.py
```

Сайт:

```bash
python manage.py runserver
```

Адрес: [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
На сайте можно посмотреть постановки, показы и брони.
Добавлять и менять данные пока можно через консоль.

## Файлы

- `models/` — классы постановок, актёров, ролей, показов, билетов и броней.
- `storage.py` — чтение и запись данных из `data/`.
- `theatre/` — настройки сайта.
- `homepage/`, `repertoire/`, `performances/`, `reservations/` — страницы.
- `tests/` — тесты.

Отменённая бронь остаётся в списке, но место снова свободно.
